# Cubby interactive hero preview

Preview: `/experiments/cubby-demo` (noindex, not linked from the portfolio).
The live `/work/cubby` hero uses the approved interactive demo. Home/Up next cards
retain their existing content. The separate preview uses the same `CubbyDemoHero`;
`CubbyProjectMedia` retains the wallpaper, menu placement, sizing, and entrance animation.

## Reference and scope

Implemented against the current source in the Cubby workspace:
`TimelineView.swift`, `EntryRow.swift`, `ScreenshotTile.swift`, `CubbyTheme.swift`,
`CubbyFonts.swift`, `ComposerView.swift`, `DaySeparator.swift`, and `EntryTransition.swift`.
Native wood/paper materials come from `WoodBackground.swift` and `ForegroundPanel.swift`.
No source files in the Cubby workspace are modified.

- Clipboard retains the existing `cubby-grizzly.js`, its current 72% feed sizing,
  and the two decorative, faded snippets. No clipboard feed actions.
- Screenshots use original fictional UI studies generated by `generate-samples.mjs`.
  Clicking selects; Command/Ctrl toggles; Shift selects ranges. Arrow keys, select all,
  Escape, and Delete operate within the focused screenshot feed. A card's Delete
  button removes that card only, matching `deleteScreenshot`; keyboard Delete removes
  the selected set. Copy writes PNG image data and displays the native green check.
- Notes are grouped chronologically by day with a bottom-aligned feed. Enter submits,
  Shift+Enter adds a line; the composer grows to 12 lines. Submission commits layout,
  scrolls the new row into view immediately, and fades from .45 to 1 over .14s.
  Focus stays in the composer. Copy feedback lasts .9s; note deletion follows selection.
  Ordinary note clicks clear selection and remember the Shift-click anchor; Shift-click
  selects ranges and Command/Ctrl-click toggles rows. Focusing or typing preserves the
  feed position. The composer fades white only while its draft contains text.
- Tabs switch by click or keyboard. Touch and trackpad gestures remain browser-native.
  The tab labels expand with the native spring response; unselected tabs show hover tooltips.
- All editable content is React component state. Reloading restores the samples.
  There are no clipboard reads, uploads, persistence, preview modals, screenshot opening,
  simulated clipboard interactions, or native-only settings menus.
- The existing `/work/cubby/cozy-face.svg` is byte-identical to the reference
  `Assets/CozyFace.svg`, including its transparent face cutout. The menu reuses it.
- Copy requires a browser that supports clipboard writes on a secure origin or localhost.
  A denied write never displays success.

## Regenerate assets

Run from the portfolio root on macOS. Set `CUBBY_SOURCE` to the read-only reference
checkout; all outputs stay in this portfolio workspace.

```sh
CUBBY_SOURCE=/path/to/cubby
mkdir -p .context/cubby-demo public/work/cubby/demo
swiftc -parse-as-library \
  "$CUBBY_SOURCE/Sources/Cubby/WoodBackground.swift" \
  "$CUBBY_SOURCE/Sources/Cubby/ForegroundPanel.swift" \
  scripts/cubby-demo/ExportNativeAssets.swift -o .context/cubby-demo/export
.context/cubby-demo/export public/work/cubby/demo
node scripts/cubby-demo/generate-samples.mjs
```

The native export uses synthetic empty chrome and SF Symbols at their source sizes
and weights, rendered at 4×. Hanken Grotesk files are copied from the approved bear
handoff; the existing `public/work/cubby/FONT-LICENSE.txt` covers the distributed fonts.

## Verification

```sh
node --experimental-strip-types --test src/components/cubby-demo/demo-interactions.test.ts
npx eslint src/components/cubby-demo src/components/CubbyProjectMedia.tsx src/components/CaseStudyPage.tsx src/app/experiments/cubby-demo
npx tsc --noEmit
npm run build
```

Browser checks: Clipboard default, tab clicks and keyboard navigation, disabled horizontal
tab gestures, vertical page scrolling, text and PNG clipboard results, selection,
individual and batch screenshot deletion, Enter/button note submission, Shift+Enter,
composer focus, row visibility/arrival timing, sample reset, and desktop/mobile geometry.
Selection behavior is covered by isolated tests. Safari has not been exercised in this environment.
